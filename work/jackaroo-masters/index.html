Summary

Unity-side services around a Cocos game

Owned the Unity-side service and social integration for a multiplayer board/card product whose core game ran in Cocos Creator.

Ownership

My responsibility

Core game logic and core multiplayer gameplay were implemented by another developer in Cocos Creator. My responsibility was the Unity-side PlayFab/social layer and the integration between the Unity shell and the Cocos game.

What I owned

  • Unity-side PlayFab/social layer
  • Unity ↔ Cocos integration

Not mine

  • Core multiplayer gameplay (Cocos Creator, another developer)
